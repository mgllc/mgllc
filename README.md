### 🔧 How I build

Every project below ships with the same baseline: static analysis (CodeQL),
secret scanning (Gitleaks, pre-commit + CI), dependency review on every PR,
and Dependabot keeping things patched. Security isn't a separate phase —
it runs on every push.
